# Bug Report Ticket Template (AI Optimized)

## Purpose
Standardizes how bugs, errors, and layout glitches are reported to AI assistants to secure fast, accurate code resolutions.

## Scope
Applies to system bug reports, crash logs, and console traces.

## Bug Report Template Blueprint

```markdown
# BUG: [Short description of the bug]

## 1. Current Defect
[Describe the unexpected behavior. What is currently failing or looking incorrect?]

## 2. Steps to Reproduce
1. Navigate to the `[Name of Screen]` portal.
2. Click on `[Target Element]`.
3. Fill input with `[Test Value]`.
4. Observe the crash or layout error.

## 3. Tech Stack Context & Logs
* **Error Logs:** [Paste exact terminal compilation log or browser console trace here]
* **Target File:** `/src/components/MyTargetFile.tsx`

## 4. Expected Outcomes
* [Describe the correct behavior. What should the system be doing under this scenario?]
```
