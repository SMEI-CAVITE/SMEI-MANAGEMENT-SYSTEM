# Enterprise Optimization Verification Checklist

This checklist must be executed and verified by software engineers or AI agents before, during, and after performing optimization work on any system module.

---

## 1. Before Optimization (Audit & Baseline Phase)

- [ ] **Module Scope Defined**: Target module and file paths identified.
- [ ] **Baseline Profiling Recorded**:
  - [ ] Render count recorded during key interactions (e.g., typing in search, opening modal).
  - [ ] Heap memory consumption noted.
  - [ ] Main-thread execution duration measured.
- [ ] **Risk Assessment Completed**:
  - [ ] Verified module critical business logic (calculations, control numbers, security rules).
  - [ ] Identified export formats (Excel, Word, PDF) generated by module.
- [ ] **Audit Report Saved**: Forensic audit report generated and saved in `docs/optimization/MODULE_AUDITS/`.

---

## 2. During Optimization (Implementation Rules)

- [ ] **Zero Business Logic Changes**:
  - [ ] Formulas and mathematical rounding logic preserved exactly.
  - [ ] Control number prefixes, templates, and formatting regex untouched.
  - [ ] Input required fields and validation rules unchanged.
- [ ] **Zero Workflow Modifications**:
  - [ ] Modal opening/closing behavior identical.
  - [ ] Step-by-step forms and gatekeeper logic preserved.
  - [ ] Status state transitions preserved.
- [ ] **Preserved Integrations**:
  - [ ] Firestore read/write patterns preserved.
  - [ ] LocalStorage keys and schema preserved.
  - [ ] API endpoints and parameters preserved.
- [ ] **Targeted Technical Refactoring Only**:
  - [ ] `React.memo` added only to sub-components with stable props.
  - [ ] `useMemo` applied to expensive filters, sorts, and aggregations.
  - [ ] `useCallback` used for handlers passed as props.
  - [ ] Event listeners and timers include proper cleanup functions.

---

## 3. After Optimization (Quality & Regression Gate)

### 3.1 Static Verification
- [ ] **TypeScript Compile Check**: `compile_applet` executed with ZERO errors (`tsc --noEmit`).
- [ ] **ESLint Check**: `lint_applet` executed with ZERO syntax or fatal import warnings.
- [ ] **Production Build Check**: `npm run build` succeeds cleanly.

### 3.2 Operational Verification
- [ ] **Excel Export Verification**: Generated Excel files match exact cell layouts, values, and formatting.
- [ ] **Word & PDF Export Verification**: Generated Word/PDF documents maintain visual structure and accurate data bindings.
- [ ] **File Upload & Parsing Verification**: Upload workflows read and process spreadsheet data correctly.
- [ ] **UI & Theme Verification**:
  - [ ] Dark/Light mode styling intact.
  - [ ] Responsive behavior (mobile/desktop) unchanged.
  - [ ] Zero visual layout shift (CLS) or clipping.
- [ ] **Console Inspection**: Browser console contains zero warnings, key errors, or unhandled promise rejections.
